| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-17 | Tampering (history state injection) | FocusPlayer popstate | mitigate | state carries only `mmFilm` id; the player never reads film data from history, only closes; items come from server props |
| T-02-18 | Tampering (XSS via titles) | FocusPlayer, FilmList | mitigate | React text nodes and `aria-label` strings only; no `dangerouslySetInnerHTML` |
