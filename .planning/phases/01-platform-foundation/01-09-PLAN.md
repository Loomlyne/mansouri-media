<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet → Worker admin paths | Requests that bypass or slip past Access (preview, deployment URLs, path tricks) |
| Access JWT → Worker | Token must be verified, never trusted by presence |
| Admin browser → /api/admin/ping | Cookie-authenticated (Access) state change |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-34 | Spoofing | forged / unsigned / HS256 / other-key JWT | mitigate | jose `jwtVerify` with remote JWKS, `algorithms: ["RS256"]`, issuer + audience, exp/nbf; unit-tested |
| T-01-35 | Elevation of privilege | path tricks (`/ADMIN`, `//admin`, `%61dmin`) | mitigate | decode + lowercase + collapse slashes, over-match, decode failure → admin; unit + e2e tests |
| T-01-36 | Elevation of privilege | admin on public preview hosts | mitigate | Worker gate runs on every host; previews vars mirror production; live check in ship 2 (01-11 T3) |
| T-01-37 | Elevation of privilege | Access policy widened by mistake | mitigate | ADMIN_EMAILS allow-list checked in the Worker as a second condition |
| T-01-38 | Elevation of privilege | dev bypass shipped to production | mitigate | no env-based bypass exists; grep gate on NEXTJS_ENV/NODE_ENV/APP_ENV in access.ts and worker.ts |
| T-01-39 | Tampering | CSRF on POST /api/admin/ping | mitigate | Origin must equal own origin when present; Access cookie is SameSite by Cloudflare default; endpoint only appends a diagnostic `checks` row |
| T-01-40 | Information disclosure | cached admin responses | mitigate | `Cache-Control: no-store` on all admin responses; no Workers Cache |
| T-01-53 | Denial of service | repeated "Run check" calls filling D1 | accept | one small row per call by two allow-listed admins; Free-plan D1 limits far above; table replaced in Phase 3 |
| T-01-SC | Tampering | npm install jose | mitigate | slopcheck [OK] in RESEARCH audit; exact version 6.2.12; lockfile |
